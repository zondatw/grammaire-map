## Explanation

Both *ser* and *estar* mean "to be," but they are not interchangeable. This rule provides a full systematic guide.

**SER — use the mnemonic DOCTOR:**
| Letter | Category | Example |
|---|---|---|
| D | Description (physical/personality) | *Es alta y simpática.* |
| O | Origin / nationality | *Soy de México. Es italiano.* |
| C | Characteristics (material, relationship) | *La mesa es de madera.* |
| T | Time (dates, days, hours) | *Hoy es martes. Son las dos.* |
| O | Occupation / profession | *Es ingeniera.* |
| R | Relationships | *Es mi hermano.* |

Also: passive voice with past participle (*El libro fue escrito por Cervantes*), events as locations (*La fiesta es en mi casa*).

**ESTAR — use the mnemonic PLACE:**
| Letter | Category | Example |
|---|---|---|
| P | Position | *Está sentado.* |
| L | Location | *Estoy en Madrid.* |
| A | Action (progressive tense) | *Estoy comiendo.* |
| C | Condition (changeable states) | *El agua está fría.* |
| E | Emotion | *Estamos contentos.* |

**Adjectives that change meaning with ser vs. estar:**

| Adjective | With ser | With estar |
|---|---|---|
| listo | clever | ready |
| aburrido | boring | bored |
| malo | bad / evil | sick |
| bueno | good (character) | tasty / feeling well |
| seguro | safe (inherently) | sure / certain |
| rico | wealthy | delicious |
| muerto | (death as fact) | dead (state) |
| vivo | lively / clever | alive |
| casado | (married as identity) | married (state) |

## Examples

| Spanish | English |
|---------|---------|
| Es aburrido. | He is boring. (personality) |
| Está aburrido. | He is bored. (current state) |
| La sopa es buena. | The soup is good (in general). |
| La sopa está buena. | The soup tastes good (right now). |
| Es listo. | He is clever. |
| Está listo. | He is ready. |
| La ciudad es segura. | The city is safe. |
| Estoy segura. | I am sure/certain. |
| Es malo. | He is bad/evil. |
| Está malo. | He is sick. |

## Pitfall

The biggest trap is using *ser* for location (except for events): locations **always** use *estar*. And the adjective meaning-shift pairs are frequently tested — memorize *listo/aburrido/malo/rico* especially, as they appear constantly in conversation.
