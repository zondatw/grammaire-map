## Explanation

**Simple negation:** Place **no** directly before the conjugated verb (and any object pronouns attached to it).

*No hablo francés.* (I don't speak French.)
*No lo veo.* (I don't see it.)

**Double negation:** Spanish requires (and allows) double negatives — this is grammatically correct, unlike in English.

| Negative word | Meaning | Example |
|---|---|---|
| nada | nothing | No tengo nada. |
| nadie | nobody | No hay nadie aquí. |
| nunca / jamás | never | No como nunca carne. |
| ningún / ninguna | no (adj.) | No tengo ningún libro. |
| tampoco | neither/nor | No me gusta tampoco. |
| ni ... ni | neither ... nor | No tengo ni tiempo ni dinero. |

**Two patterns with negative words:**
1. *No* before verb + negative word after: *No veo a nadie.*
2. Negative word before verb (no *no* needed): *Nadie sabe la respuesta.*

Both are correct; pattern 2 is more emphatic.

**Ningún/ninguna** shortens to *ningún* before a masculine singular noun: *ningún problema*, *ninguna idea*.

## Examples

| Spanish | English |
|---------|---------|
| No hablo inglés. | I don't speak English. |
| No tengo nada. | I don't have anything. / I have nothing. |
| No viene nadie. | Nobody is coming. |
| Nunca como carne. | I never eat meat. |
| No quiero ni café ni té. | I want neither coffee nor tea. |
| A mí tampoco me gusta. | I don't like it either. |

## Pitfall

Translating English "I don't have anything" literally as *"No tengo nada"* feels redundant to English speakers, but it is the correct Spanish form. **Never** omit *no* when the negative word follows the verb — *"Tengo nada"* is ungrammatical.
