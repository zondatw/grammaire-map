## Explanation

**Direct object pronouns** (answer "what?" or "whom?"):
| Person | Pronoun |
|---|---|
| yo | me |
| tú | te |
| él | lo |
| ella | la |
| nosotros | nos |
| vosotros | os |
| ellos | los |
| ellas | las |

**Indirect object pronouns** (answer "to/for whom?"):
| Person | Pronoun |
|---|---|
| yo | me |
| tú | te |
| él/ella/usted | le |
| nosotros | nos |
| vosotros | os |
| ellos/ellas/ustedes | les |

**Placement rules:**
- **Before a conjugated verb:** *Lo veo. Le doy el libro.*
- **Attached to an infinitive:** *Quiero verlo. / Lo quiero ver.*
- **Attached to a gerund:** *Estoy leyéndolo. / Lo estoy leyendo.*
- **Attached to affirmative commands:** *¡Dámelo!* (Give it to me!)

**When both pronouns appear together:** Indirect comes first, then direct: *Me lo da.* (He gives it to me.) If both are third person, *le/les → se*: *Se lo doy.* (I give it to him/her/them.)

**Leísmo:** In Spain, *le* is commonly used as a direct object pronoun for masculine persons: *Le vi ayer.* This is accepted but regional.

## Examples

| Spanish | English |
|---------|---------|
| Lo veo todos los días. | I see him/it every day. |
| Te llamo mañana. | I'll call you tomorrow. |
| Le doy el libro. | I give him/her the book. |
| Se lo mando ahora. | I'm sending it to him/her now. |
| ¿Me lo puedes dar? | Can you give it to me? |
| ¡Escúchame! | Listen to me! |

## Pitfall

When indirect and direct object pronouns are combined, the indirect always comes first — *me lo*, *te la*, *se los*, never reversed. Also, *le* and *les* (indirect) become *se* before *lo/la/los/las*: never say *"le lo doy"* — it must be *"se lo doy"*.
