## Explanation

Italian has two sets of demonstrative adjectives: **questo** (this/these — near the speaker) and **quello** (that/those — far from the speaker).

**Questo** has four regular forms:

| | Singular | Plural |
|---|---|---|
| Masculine | questo | questi |
| Feminine | questa | queste |

Before a vowel, *questo* and *questa* can elide: *quest'uomo*, *quest'amica*.

**Quello** follows the same pattern as the definite article (il/lo/la/l'/i/gli/le):

| Context | Form | Example |
|---------|------|---------|
| masc. sing. before consonant | quel | *quel libro* |
| masc. sing. before s+cons, z, gn | quello | *quello studente* |
| masc. sing. before vowel | quell' | *quell'amico* |
| masc. pl. before consonant | quei | *quei libri* |
| masc. pl. before s+cons, z, gn | quegli | *quegli studenti* |
| fem. sing. before consonant | quella | *quella casa* |
| fem. sing. before vowel | quell' | *quell'amica* |
| fem. pl. | quelle | *quelle case* |

## Examples

| Italian | English |
|---------|---------|
| questo libro | this book |
| questa casa | this house |
| quel ragazzo | that boy |
| quello zaino | that backpack |
| quell'amica | that friend (f.) |
| quei ragazzi | those boys |
| quegli uomini | those men |
| quelle ragazze | those girls |

## Pitfall

Do not treat **quello** like a regular 4-form adjective (quello/quella/quelli/quelle). Its forms mirror the definite articles. Saying *quelli libri* instead of *quei libri* is a common mistake.
